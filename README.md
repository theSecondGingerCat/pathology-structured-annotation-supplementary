# Supplementary Material

## Pathology-Knowledge-Guided Structured Annotation for Clinical Speech Audio

This repository provides the supplementary material accompanying the paper **“Pathology-Knowledge-Guided Structured Annotation for Clinical Speech Audio.”**

### Files

- [`supplementary_material_final.pdf`](supplementary_material_final.pdf): compiled supplementary material for review.
- [`supplementary_material_final.tex`](supplementary_material_final.tex): LaTeX source.

### Contents

The supplementary material includes:

1. Population-wise support of the 22-label schema.
2. Held-out validation of the frozen weak-label pipeline.
3. One-at-a-time threshold sensitivity analysis.
4. Test-set label and dimension support.
5. Complete deterministic weak-label generation rules.
6. Bootstrap uncertainty analyses for S4 vs. S0 and SCSA vs. Qwen3-Omni.
7. Flat-22 label-level error analysis.
8. SCSA architecture and optimization configuration.
9. Complete Qwen3-Omni Q0--Q3 prompts, demonstration formatting, and demonstration sets.
10. Confirmed audio preprocessing details.
11. JSON parsing, normalization, and schema-aware scanning-repair procedures.

The main paper reports the central experimental results; this repository contains the additional analyses and reproducibility details referenced from the paper.
